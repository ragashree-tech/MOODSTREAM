# MOODSTREAM
Ever spent more time deciding what to watch than actually watching it? Yeah, same. So I built this.

Mood Stream is a simple C++ console app ,you tell it your mood, it picks a movie for you. No more endless scrolling or arguing over the remote.

## Backstory

This was one of my first real programs, built with the C++ basics I picked up in my college bridge course. Still figuring things out, but this one actually works and I'm proud of it.

## The one thing it doesn't do (yet)

It's a console app, so once you close it, it forgets everything. No memory of past picks. I'll fix this once I learn more about saving data to files as if for now, it's a "run it fresh every time" kind of app.

## Made with
C++, Dev C++, and mild frustration over indecisiveness.
